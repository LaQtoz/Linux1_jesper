Vi kan skapa filer genom att skriva: 
- touch "file.txt"
- vim "file.txt"

för att skapa en map kan vi skriva:
- mkdir "MinMapp"

Vi kan tabort filer genom att skriva:
rm "file.txt"
eller för att ta bort en mapp och allt som den innehåller
rm -r "MinMapp"

Vi kan flytta på filer genom att skriva:
mv file.txt MinMapp/
